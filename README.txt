SNAP & ROLL WEBSITE

Open index.html in a browser to view the homepage.

Pages:
- index.html: Homepage
- products.html: Film listing with brand, ISO, film-type and sorting filters
- kodak-gold.html, kodak-ultramax.html, ilford-pan.html, fuji-200.html: Product detail pages
- checkout.html: Shopping cart and checkout form

The website uses HTML, CSS and vanilla JavaScript. Product images are stored in assets/.
Cart contents are stored in the browser's localStorage.
